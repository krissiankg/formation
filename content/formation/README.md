# Contenu de départ de la formation (archive)

Ces fichiers ont servi à **remplir une seule fois** la base de données avec la formation ADAPT (octobre 2026).

**Ils ne sont plus la référence.** Les cours, quiz, séances et la liste de préparation se modifient
désormais depuis le tableau de bord admin :

- **Admin → Programme** : modules, leçons (éditeur avec aperçu en direct et insertion d'images), ordre ↑ ↓
- **Admin → Tests** : quiz et questions
- **Admin → Séances** : calendrier des deux classes
- **Admin → Todos** : liste de préparation

Modifier un fichier ici ne change rien sur le site.
