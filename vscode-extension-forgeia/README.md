# Forge IA Assistant — Extension VS Code

Extension officielle de la formation **FORGE IA**, connectée directement à votre passerelle IA privée sécurisée (`https://ia.guelichweb.store/v1`).

## ✨ Fonctionnalités
- 🤖 **Assistant latéral intégré** : posez vos questions, demandez des explications et générez du code directement depuis la barre latérale VS Code.
- ⚡ **Expliquer le code sélectionné** : clic droit ou raccourci pour obtenir l'explication ligne par ligne en français.
- 🛠️ **Corriger / Optimiser le code** : détection de bugs et refactorisation instantanée.
- 🔐 **Connexion sécurisée par clé Étudiant** : accès exclusif aux modèles ultra-rapides (DeepSeek, etc.).

## 🚀 Installation & Utilisation
1. Dans VS Code, ouvrez la palette de commandes (`Ctrl+Shift+P` ou `Cmd+Shift+P`).
2. Choisissez **Extensions: Install from VSIX...**.
3. Sélectionnez le fichier `forgeia-assistant-1.0.0.vsix`.
4. Cliquez sur l'icône **Forge IA** dans la barre latérale gauche.
5. Cliquez sur **⚙️ Clé** et collez votre clé étudiante personnelle récupérée sur votre [Espace Apprenant](https://forgeia.guelichweb.store/espace/ressources).
