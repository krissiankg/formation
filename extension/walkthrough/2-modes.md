# Choisis un mode ADAPT

Ouvre **Kilo Code** (icône dans la barre de gauche), puis choisis un mode dans la liste des agents :

- **forgeia-acquerir** : comprendre un concept, sans toucher à tes fichiers.
- **forgeia-decortiquer** : lire et expliquer un code ou une maquette.
- **forgeia-assigner** : coder par petites étapes que tu valides.
- **forgeia-personnaliser** : adapter un modèle à ta marque.
- **forgeia-tester** : vérifier et corriger.
- **forgeia-coach** : t'aider à trouver toi-même, sans donner la solution.
