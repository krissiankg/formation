# Connecte ton compte FORGE IA

Ton crédit IA est inclus dans ta formation. Pour l'utiliser, relie FORGEIA CODE à ton compte :

1. Ouvre ton espace FORGE IA → **Mon assistant IA**.
2. Clique sur **Connecter FORGEIA CODE**. Si VS Code demande d'autoriser l'extension à ouvrir le lien, clique sur **Ouvrir**.

Ton crédit restant s'affiche ensuite en bas à gauche de VS Code.
