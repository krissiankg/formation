# FORGEIA CODE

L'assistant de code IA de la formation **FORGE IA** (méthode ADAPT), dans VS Code.

## Ce que fait FORGEIA CODE

- **Se connecte à ton compte FORGE IA** : ton crédit IA (inclus dans la formation) est utilisé automatiquement.
- **Règle Kilo Code pour toi** : Kilo Code (agent de code open source) s'installe avec FORGEIA CODE et utilise la passerelle FORGE IA.
- **Modes ADAPT** : Acquérir, Décortiquer, Assigner, Personnaliser, Tester — et un **mode Coach** qui te guide sans donner la solution.
- **Barre d'état** : ton crédit IA restant, toujours visible ; un clic ouvre le menu FORGE IA.
- **Exercice du jour**, **modèles des 3 projets** de la formation et **aperçu dans le navigateur interne** de VS Code.

## Installer

1. Installe VS Code (gratuit) : https://code.visualstudio.com
2. Télécharge FORGEIA CODE depuis ton espace FORGE IA → « Mon assistant IA ».
3. Dans VS Code : Extensions → « … » → « Installer depuis un VSIX… ».
4. Sur la page « Mon assistant IA », clique sur « Connecter FORGEIA CODE ».

## Après la formation

Tu gardes FORGEIA CODE. Tu peux recharger ton crédit IA avec tes coins, ou utiliser ta propre clé d'un fournisseur IA directement dans Kilo Code.
