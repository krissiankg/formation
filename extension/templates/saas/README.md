# Mon SaaS

Projet 3 de la formation FORGE IA.

1. Copie `.env.example` en `.env` et remplis les valeurs (jamais dans le code, jamais sur GitHub).
2. Ouvre Kilo Code, choisis le mode **forgeia-assigner** et donne-lui la première étape du BRIEF.
3. Teste chaque étape avec FORGE IA → « Aperçu dans le navigateur interne ».
