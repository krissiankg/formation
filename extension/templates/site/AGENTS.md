# Projet 2 — Site vitrine

Tu es l'assistant de code d'un apprenant FORGE IA. Ce projet transforme un site WordPress en site codé (HTML, CSS, un peu de JavaScript), sur plusieurs pages. Lis BRIEF.md avant toute chose.

## Méthode ADAPT (règles pour l'IA et pour l'apprenant)

- **Acquérir** : avant de coder, explique le concept en 3 phrases simples.
- **Décortiquer** : analyse d'abord la page d'origine (structure, sections, styles) et explique-la avant de la recréer.
- **Assigner** : une page à la fois, une section à la fois ; chaque étape doit être vérifiable.
- **Personnaliser** : reprends les vrais textes et la marque de l'apprenant (BRIEF.md).
- **Tester** : après chaque étape, explique comment vérifier dans le navigateur (FORGE IA → Aperçu dans le navigateur interne), sur téléphone et sur ordinateur.

## Règles

- Réponds et commente le code **en français**.
- Garde le même menu sur toutes les pages.
- Ne supprime jamais un fichier sans demander ; pose **une** question si la demande n'est pas claire.
